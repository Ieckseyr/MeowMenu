# MeowMenu 全量测试清单

测试入口挂在**主菜单**上：`/mmenu` → 点「§e菜单功能测试」→ `t_form_root`，再从这里进各分支
（`Meowdata/MeowMenu/data/t_*.json` 是测试菜单数据；数据改动 `/mmenu reload` 立即生效，不用重启）。

> 想单独测某个菜单（包括你自己的菜单）：用编辑器给主菜单加一个 `submenu` 按钮指向它即可 ——
> `/mmenu admin → 选菜单 → 添加菜单项 → 普通按钮 → 类型选 submenu → 值填菜单ID`。

前置检查：

```
/mnpc status                 应显示 HologramLib 已连接 (ABI 0x011B00)、NPC 域=可用、箱子界面域=可用
                             （表单模式即普通 SimpleForm；无缝翻页请看 §3 NPC / §4 箱子）
```

|---|---|---|

| 0.4 | `/mmenu ui` 选「跟随菜单」 | 之后各菜单回到各自配置的样式 |

## 1. 表单模式：子菜单 = 正常表单切换

> **说明（已实测确认）**：原版 JSON-UI 表单在点击按钮时**客户端就会关闭表单**，LL 也在回传后释放了对该
> 表单的跟踪，所以"同一条表单换内容"做不到；DS 侧只能开新表 → 表现为一次关闭/打开。
> 这是表单模式的固有行为。**需要无缝翻页/换层请用 NPC 对话或箱子样式**（§3 / §4，两条线均已 0 闪烁）。
> 之前基于 ddui-lseAPI 的拦截式通道已按此结论移除。

| # | 操作 | 预期现象 |
|---|---|---|
| 1.1 | 主菜单 → 「菜单功能测试」 → 点「进入设置菜单（表单→表单）」 | 正常切换到设置菜单的表单（会有一次关闭/打开，属预期） |
| 1.2 | 设置菜单 → 点「进入第三层」→ 点「返回上一层」 | 逐层切换正常，内容正确 |
| 1.3 | 设置菜单 → 点「给我一颗钻石」 | 命令执行；菜单关闭（表单模式下命令类按钮执行后菜单关闭 = 预期行为） |
| 1.4 | 根菜单 → 点「打开菜单编辑器」 | 直接进入编辑器，菜单不会被弹回/盖住 |
| 1.5 | 任意表单按 `ESC` 关掉 → 再 主菜单 → 「菜单功能测试」 | 正常打开（不会"打不开"） |

## 2. DogeUI 硬规则（启用 DogeUI ⇒ 固定表单）

编辑器里也能看到提示：`/mmenu admin → 选 t_form_settings → 显示模式` 会写明"本菜单含菜单编辑器入口/已启用 DogeUI → 固定表单"。

| # | 操作 | 预期现象 | 日志对照 |

| 4.2 | 点「给一个苹果」 | 命令执行，**箱子界面保持不关** | `箱子界面点击: … slot=0 → 按钮#0` + `箱子界面已就地刷新: …` |

| 4.4 | 点「下一页 →」 | **即时换页**（无 0.35s 等待、无闪烁） | `箱子界面已就地刷新: … (第 2 页 …)` |

## 6. 诊断手段

```
/mnpc status                     HologramLib 连接状态、NPC/箱子两个能力域、进行中的对话与数量
getNpcMenuStatus()               同上（LSE 侧）
getMenuNpcMode(菜单ID)           该菜单的模式配置与"可点击按钮数"（判断是否该分页）
```

日志关键字：`NPC 对话菜单已打开/已重开`、`NPC 对话分页:`、`箱子界面已打开/已就地刷新`、`箱子界面点击:`、
`菜单进入子菜单(表单/箱子/对话):`。
